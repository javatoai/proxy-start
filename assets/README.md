# Proxy Start 品牌资源

`proxy-start.ico` 是安装快捷方式使用的多尺寸图标，包含 16、32、64 像素的 PNG 图像条目。

图标源定义位于 [`internal/ui/brand.go`](../internal/ui/brand.go)：蓝色圆角方块和白色双向路径/连接节点由 Go 几何绘制与同源 SVG 定义生成。目录中的 PNG 与 ICO 均为本地代码生成的发布资源，不依赖外网下载或 AI 生成。

`proxy-start-16.png`、`proxy-start-32.png` 和 `proxy-start-64.png` 是用于人工检查清晰度的预览尺寸。
